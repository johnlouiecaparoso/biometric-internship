# InternTrack Logo

This folder contains the logo files for InternTrack: Biometric Internship Attendance System.

## Usage

Place your logo files here and reference them in the components:
- `logo.png` - Main logo for desktop
- `logo-mobile.png` - Optimized logo for mobile devices
- `favicon.ico` - Favicon for browser tabs

## Current Implementation

The system currently uses a placeholder GraduationCap icon from Lucide React. Replace the icon references in the components with actual logo images:

```tsx
<img src="/logo.png" alt="InternTrack Logo" className="w-8 h-8" />
```
